# Bandai Account Creator

A powerful automation tool designed to simplify the process of creating **Bandai Namco accounts** for use with **Dragon Ball Legends**.

## Features

* Automated Bandai account creation
* Temporary email integration
* Automated email verification
* Browser automation powered by Selenium
* Configurable run count and delays
* Automatic results logging
* Safe cancellation with `CTRL+C`
* Clean console interface
* Backend-controlled access

## 🎮 What Is It Used For?

Bandai Account Creator helps streamline the process of creating Bandai Namco accounts that can be used to link with your **Dragon Ball Legends** accounts.

Instead of manually going through the registration and verification process for each account, the tool automates the workflow to save time and reduce repetitive tasks.

## 📋 Requirements

Before running the program, make sure you have:

* Windows 10 or Windows 11
* Google Chrome installed
* A valid license or authorization to use the software
* An active internet connection

The program uses **Google Chrome** and **ChromeDriver** for browser automation.

## 🚀 Getting Started

1. Download the latest release.
2. Extract the program files into a folder.
3. Make sure all required dependencies are included.
4. Launch `Bandai Creator.exe`.
5. Configure your desired settings.
6. Start the account creation process.

> **Note:** The software may require additional dependencies depending on the version you receive.

## ⚙️ Configuration

The program supports configuration options such as:

* Number of accounts/runs
* Delay between runs
* Headless browser mode
* Results output file

Configuration options may vary depending on the version of the software.

## 📁 Output

The program can automatically save results to a JSON Lines file:

```text
results.json
```

Each completed run may contain information such as:

* Run number
* Account email
* Account password
* Status
* Error information
* Timestamp

Keep generated account credentials secure and do not share them publicly.
